# Security Policy

DwellSafe handles sensitive property, identity, and transaction information. Security requirements are enforced during design and implementation.

## Required practices

- Use secure authentication and authorization flows.
- Validate all incoming user input on the server.
- Protect private data and verification records.
- Never commit secrets or credentials.
- Keep environment variables in `.env` and document them in `.env.example`.
- Review access to landlord, agent, and listing management APIs.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the project maintainers using the repository's secure reporting channel.
